### Document Translator

A web application that allows users to upload documents and translate them into a selected language using the Google Translate API.

• Designed and developed the user interface and supporting visual assets.
• Designed and implemented the SQL database used to manage users and uploaded files.
• Connected the front end to the database and backend services.
• Implemented user authentication, session management, and file upload/download functionality.
• Worked as the UI developer within a team environment using React and Python-based backend services.
